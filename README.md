# Deposombe's Homebrew tap

Casks for Deposombe's Mac apps.

## Rapidfire

A keyboard launcher for the Mac. About the app: https://deposombe.com/rapidfire/

```bash
brew trust --cask deposombe/tap/rapidfire
brew install --cask deposombe/tap/rapidfire
```

Homebrew 7 and later install a cask from outside Homebrew's own collection only after it has been trusted; that is the first line. Older versions need only the second.

Rapidfire updates itself once installed.
