# Deposombe's Homebrew tap

Casks for Deposombe's Mac apps.

## Rapidfire

A keyboard launcher for the Mac. About the app: https://deposombe.com/rapidfire/

```bash
brew install --cask deposombe/tap/rapidfire
```

Rapidfire updates itself once installed.
